# 🏔️ Dmitry_Lixxx на бездорожье

> Hill Climb Racing–подобная аркада на Phaser 3 + Planck.js. Стример Дмитрий Ликкс едет на легендарной «Ниве» через бесконечное процедурное бездорожье.

---

## 🎮 О игре

**Dmitry_Lixxx на бездорожье** — это 2D-аркада с реалистичной физикой автомобиля, созданная как дань классическому *Hill Climb Racing*. Игрок управляет Нивой, на которой стример Дмитрий Ликкс пытается проехать как можно дальше по бесконечному холмистому рельефу, собирая монеты и канистры с топливом, не перевернувшись и не разбившись.

Игра построена на **физическом движке Box2D** (через Planck.js) — настоящая симуляция колёсной подвески, трения шин о землю и инерции кузова. Каждый холм, каждый прыжок и каждое приземление просчитываются физикой в реальном времени.

---

## ✨ Особенности

### 🚗 Реалистичная физика автомобиля
- **WheelJoint** с пружинной подвеской (5 Hz, damping 0.7) — настоящая симуляция амортизаторов
- Два ведущих колеса с независимым мотором (max torque 60)
- Многослойный кузов: основное тело + кабина для правильного центра масс
- Bullet-mode для стабильной коллизии на высоких скоростях
- Трение шин 1.1 — реалистичное сцепление с грунтом

### 🏔️ Процедурный рельеф
- Бесконечная генерация местности на лету (5 октав sine-noise)
- Рельеф усложняется с расстоянием — после 4000 м появляются более крутые подъёмы
- Каждый сегмент — отдельное статическое физическое тело с трением грунта
- Деревья и декорации расставляются процедурно

### 🎨 Графика
- **Нива** нарисована процедурно через Phaser Graphics → texture: кузов, кабина, тонированные стёкла, фары, бамперы, дверная ручка
- **Дмитрий Ликкс** — голова стримера с наушниками (фиолетовые подушки), микрофоном на штанге, тёмными очками и щетиной
- **Колёса** с протектором, 5 спицами и хабом
- **Параллакс-фон** в 4 слоя: градиентное небо, солнце с glow, дальние горы, средние горы, ближние холмы
- **Деревья** на рельефе для масштаба

### 🔊 Звук (Web Audio API)
- **Двигатель**: 2 осциллятора (sawtooth + square) через lowpass-фильтр — pitch и громкость зависят от газа и скорости
- **Монеты**: классический 8-bit «блинг» (square wave, 880→1760 Hz)
- **Канистры**: мягкий sine-свип (440→880 Hz)
- **Краш**: белый шум через lowpass (800 Hz) с exponential decay

### ⚡ Геймплей
- **Топливо** расходуется на холостом ходу (1.2/сек) и при газе (3.5/сек). Канистра = +35
- **Монеты** (₽) собираются кластерами по 3, можно потратить на апгрейды (в будущих версиях)
- **Дистанция** считается в метрах, сохраняется рекорд в localStorage
- **Game over** в 4 случаях:
  - 🔴 Топливо закончилось и скорость ~0
  - 🔴 Нива перевернулась (на крыле >1.5 сек)
  - 🔴 Дмитрий ударился головой о землю
  - 🔴 Нива упала за пределы мира

### 🎯 Партиклы
- **Дым выхлопа** — серые частицы из трубы при газе
- **Грязь из-под колёс** — коричневые частицы при пробуксовке, интенсивность зависит от скорости вращения
- **Искры монет** — золотые вспышки при сборе

### 📱 Управление
- **Тач**: правая кнопка — ГАЗ, левая — ТОРМОЗ/назад
- **Клавиатура**: → / D / W / Space — газ, ← / A / S — тормоз
- Полная поддержка мобильных устройств и Telegram WebView

### Почему именно этот стек?

- **Phaser 3** — самый зрелый HTML5 игровой движок, тысячи туториалов, встроенные сцены/спрайты/партиклы/камера
- **Planck.js** — порт Box2D на JavaScript, идеален для колёсной физики (WheelJoint, motor, suspension). Оригинальный Hill Climb Racing тоже на Box2D
- **Без сборщика** — нулевая конфигурация, мгновенный запуск, простота деплоя
- **Один файл** — легко делиться, хостить где угодно, встраивать в Telegram Mini App

## 🎯 Цель игры

Проехать как можно дальше, собирая монеты и канистры с топливом, не перевернув Ниву и не ударившись головой о землю. Рекорд дистанции сохраняется между сессиями.

**Очки** = дистанция (м) + монеты × 5

## 🕹 Советы по игре

1. **Не газуй на спусках** — Нива клюёт носом и можно перевернуться через руль
2. **Тормози перед крутыми подъёмами** — перенос веса на заднюю ось = лучше сцепление
3. **Используй инерцию** — на вершине холма чуть сбрось газ, чтобы мягко приземлиться
4. **Собирай канистры** — без топлива игра заканчивается, даже если не разбился
5. **Не тормози резко на спуске** — Нива может кувыркнуться вперёд
6. **Следи за головой стримера** — если голова касается земли, game over мгновенно

## 📐 Архитектура кода

```
┌─ START SCREEN (CSS overlay)
├─ HUD (CSS overlay: distance, coins, fuel, best)
├─ TOUCH CONTROLS (CSS overlay: gas/brake pedals)
├─ GAME OVER SCREEN (CSS overlay: stats + restart)
│
└─ PHASER GAME
   ├─ OffroadScene (main scene)
   │   ├─ create() — текстуры, рельеф, машина, параллакс, партиклы
   │   ├─ update() — input, physics step, sync sprites, camera, fuel, pickups, game-over checks
   │   └─ _gameOver() — финальная статистика, сохранение рекорда
   │
   ├─ TERRAIN GENERATOR
   │   ├─ generateTerrainPoint(i) — 5-octave sine noise
   │   ├─ extendTerrain() — генерит новые сегменты на лету
   │   └─ redrawTerrain() — перерисовывает fills + grass
   │
   ├─ CAR FACTORY
   │   └─ createCar() — body + 2 wheels + 2 WheelJoint
   │
   ├─ TEXTURE GENERATOR
   │   └─ generateTextures() — Нива, колёса, голова, монета, канистра, частицы
   │
   ├─ PARALLAX BACKGROUND
   │   └─ createParallax() — sky + sun + 3 layers mountains
   │
   └─ AUDIO (GameAudio class)
       ├─ _setupEngine() — 2 осциллятора + фильтр + gain
       ├─ setEngine() — модуляция pitch/gain/filter
       ├─ coin() / fuel() / crash() — SFX
       └─ stopEngine() — fade-out
```

## 📊 Конфигурация

Все ключевые параметры вынесены в объект `CFG` в начале скрипта:

```javascript
const CFG = {
  GRAVITY_Y: 1400,              // сила гравитации (px/s²)
  CAR_W: 90, CAR_H: 32,         // размеры кузова
  WHEEL_RADIUS: 22,             // радиус колёс
  SUSPENSION_FREQ: 5,           // жёсткость подвески (Hz)
  SUSPENSION_DAMP: 0.7,         // демпфирование подвески
  MOTOR_TORQUE: 60,             // мощность мотора
  TERRAIN_STEP: 28,             // шаг точек рельефа
  FUEL_MAX: 100,                // объём бака
  FUEL_DRAIN_GAS: 3.5,          // расход при газе (/сек)
  // ... и др.
};
```

Меняй значения и тестируй — например, `MOTOR_TORQUE: 100` сделает Ниву мощнее, а `SUSPENSION_FREQ: 8` — подвеску жёстче.
